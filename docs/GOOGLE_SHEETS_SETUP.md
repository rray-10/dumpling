# 訂單串接 Google Sheet 設定步驟

結帳送出後，訂單會寫進你的 Google 試算表。整個流程約 10 分鐘，只需要做一次。

```
結帳頁 ──POST──▶ Google Apps Script（網頁應用程式）──▶ Google 試算表
                 ├ 驗證資料、用 Products 價格表重算金額
                 ├ 產生訂單編號（JB + 日期 + 當日流水號）
                 └ 寫入 Orders / OrderItems，可選寄信通知
```

## 1. 建立試算表與 Apps Script

1. 到 Google 雲端硬碟建立一份**新的空白試算表**，命名例如「金邊鍋貼訂單」。
2. 選單 **擴充功能 → Apps Script**。
3. 刪掉預設程式碼，把本專案 `gas/Code.gs` 的內容整份貼上，按儲存。
4. （選填）想收新訂單通知信：把 `CONFIG.NOTIFY_EMAIL` 改成你的信箱。
5. 上方函式選單選 **`setup`**，按 **執行**。第一次會要求授權，依畫面同意即可
   （會看到「Google 尚未驗證這個應用程式」，選「進階 → 前往…」，因為這是你自己的程式）。
6. 回到試算表，會看到三個分頁：`Orders`、`OrderItems`、`Products`。

## 2. 部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**。
3. 執行身分：**我**；誰可以存取：**所有人**。
4. 按部署，複製「網頁應用程式網址」（結尾是 `/exec`）。

## 3. 把網址放進網站

打開 `index.html`，找到這一行，貼上網址：

```js
const ORDER_ENDPOINT = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

commit 並合併後，網站就會把訂單送到試算表。網址留空時，網站只會顯示示範訂單，不會寫入任何資料。

## 試算表分頁說明

| 分頁 | 用途 |
|---|---|
| `Orders` | 一張訂單一列。**狀態**欄是下拉選單（新訂單／製作中／可取餐／已完成／已取消），由店家手動更新。 |
| `OrderItems` | 每個品項一列，用訂單編號對應 `Orders`。 |
| `Products` | **價格表**。後端以這裡的價格計算金額；改價、下架（把「上架」取消勾選或改成 FALSE）直接改這裡。 |

> 改價時要同步修改 `index.html` 裡 `PRODUCTS` 的價格，否則畫面顯示的金額與實際收費會不一致。
> 新增商品時，兩邊都要新增，且商品 ID 要相同。

## 之後修改程式碼要重新部署

改了 `Code.gs` 之後：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。
網址不會變。只改試算表內容（價格、狀態）不需要重新部署。

## 安全與限制

- 前端只送「商品代號＋數量」，**金額一律由後端重算**，竄改前端價格沒有用。
- 每筆訂單帶有識別碼，連點或網路重試不會產生重複訂單。
- 以 `= + - @` 開頭的文字會被加上單引號，避免試算表公式注入。
- 網頁應用程式網址是公開的，任何人知道網址都能送單。目前的防護是資料驗證與重複檢查；
  如果之後遇到惡意灌單，可以再加上驗證碼或每支電話的頻率限制。
- Apps Script 有每日配額（一般帳號寄信約 100 封／日），一般店家訂單量足夠。
- 訂單送出失敗時，購物車會保留，顧客可以重試。
